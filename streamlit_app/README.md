# Titanic Survival Predictor

A machine learning web application that predicts Titanic passenger survival using a trained Logistic Regression model deployed through Databricks Model Serving.

Users can enter passenger details in a Streamlit interface and receive a prediction from the deployed model.

## Project Overview

- **Machine Learning Algorithm:** Logistic Regression
- **Prediction Target:** Passenger survival
- **Frontend:** Streamlit
- **Model Serving:** Databricks Model Serving
- **Model Registry:** MLflow / Databricks Unity Catalog
- **Input Features:** 33 engineered features

## Features

- Interactive passenger information form
- Passenger class, age, sex, fare, and family information
- Embarkation port, passenger title, and cabin deck inputs
- Feature engineering and one-hot encoding
- Real-time predictions through a Databricks serving endpoint
- Prediction results displayed in a styled web interface

## Machine Learning Workflow

1. Collect and explore the Titanic dataset.
2. Clean and preprocess the data.
3. Perform feature engineering and categorical encoding.
4. Split the data into training and testing sets.
5. Train a Logistic Regression classifier.
6. Evaluate the model.
7. Track experiments with MLflow.
8. Register the trained model in Databricks.
9. Deploy the model using Databricks Model Serving.
10. Connect the deployed model to the Streamlit application.

## Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd Titanic-Survival-Predictor
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Configure Databricks credentials

Create `.streamlit/secrets.toml` locally with your Databricks workspace host, OAuth client ID, and OAuth client secret.

Do not commit this file or share your credentials publicly. Configure equivalent secrets securely when deploying the app.

### 5. Run the application

```bash
python -m streamlit run titanic_app.py
```

## Databricks Model Serving

The application sends the engineered passenger features to a Databricks Model Serving endpoint. The deployed model returns a binary prediction:

- `1` — Predicted to survive
- `0` — Predicted not to survive

The application has been tested against the deployed endpoint using three sample passenger profiles. All three predictions matched between the Streamlit application and Databricks.

## Security

- Keep OAuth credentials outside source control.
- Exclude `.streamlit/secrets.toml` from Git.
- Never commit access tokens, passwords, or client secrets.

## Limitations

Predictions are generated by a trained machine learning model and are not guarantees of actual outcomes. Test-case consistency does not establish overall model accuracy.
